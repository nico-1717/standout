# Security policy

If you found a security problem in Standout, please **do not open a public issue**.
Report it privately here: <https://github.com/nico-1717/standout/security/advisories/new>

Please include the page or endpoint, the steps to reproduce it, and what you expected to happen.
I will answer as soon as I can and credit you if you want.

Standout is a one-person project, so there is no bug bounty.
